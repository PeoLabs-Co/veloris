# Veloris 🛒

A lightweight, headless e-commerce platform and admin dashboard. This project is built as a collaborative open-source initiative by the PeoLabs community.

## 🏗 Architecture & Team

Veloris is built using a modular, API-driven monorepo structure to allow parallel development across different tech stacks.

- **Frontend (Storefront):** React & Tailwind CSS (Led by Lucy & Samuel)
- **Frontend (Admin Dashboard):** Vanilla HTML/CSS/JS (Led by Diana & Samuel)
- **Backend (API):** Node/Python [TBD] (Led by Barbra & Simon)
- **Automations:** n8n webhooks for order alerts (Led by Simon)

## 📂 Repository Structure

veloris/

## 🚀 Icebreaker Task (Start Here)

Before we write any application code, we need to ensure everyone's Git environment is working perfectly.

1.  Clone this repository to your local machine.
2.  Create a new branch: git checkout -b feature/add-[your-name]
3.  Open MEMBERS.md and add your Name, GitHub handle, and your primary role on this project.
4.  Commit and push your branch.
5.  Open a Pull Request against the main branch.
    Once everyone's PR is merged, we will populate the GitHub Project Board with the first UI and API tasks.
